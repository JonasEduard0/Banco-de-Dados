# Banco de Dados

Repositório destinado aos meus estudos sobre Banco de Dados, modelagem de dados, SQL e MySQL.

## Conteúdos

### Modelagem de Banco de Dados

- Modelo conceitual
- Modelo lógico
- Modelo físico
- Entidades e relacionamentos
- Cardinalidade
- Generalização e especialização
- Chaves primárias e estrangeiras
- Dependências funcionais
- Normalização até a 3ª Forma Normal (3FN)

### SQL e MySQL

- Criação de bancos e tabelas
- Tipos de dados
- Inserção, consulta, atualização e exclusão de dados
- Funções de agregação
- Filtros e ordenação
- Agrupamento
- JOINs
- Views
- Alteração e exclusão de tabelas
